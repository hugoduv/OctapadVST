Plugin to use along with the Roland Octapad SPD-30. The goal is to able to launch personalized samples from the computer with a midi link to the device. 
It is made to be ready to use as a Standalone for live music purposes.

Roland Octapad SPD-30 -> midi (USB) link -> Computer with OctapadVST -> Soundcard -> line out DI/ soundbox -> FOH

The presets should be buildable from the VST and it should be easy to swith in between presets.
